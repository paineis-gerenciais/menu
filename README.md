# menu

Menu geral dos Painéis Gerenciais: logo, fundo e um botão para cada painel (abre em nova aba).

Publicação: GitHub Pages → https://paineis-gerenciais.github.io/menu/

## Arquivos

- `index.html` — menu (HTML + CSS, sem JavaScript)
- `em-breve.html` — destino do botão "Outros"
- `assets/` — imagens WebP otimizadas (720 px de largura; logo e fundo inclusos)

## Adicionar ou trocar um painel

Edite o `href` do `<li>` correspondente em `index.html`. Para um botão novo, salve a imagem em WebP com 720 px de largura em `assets/` e copie um `<li>` existente.
